# SQL Practice & Database Learning Resources

A structured collection of **SQL exercises, query examples, lecture slides, and reference documents** for practicing relational databases.

> **Best for:** Students and self-learners familiar with basic SQL syntax who want guided practice with queries, filtering, joins, aggregation, and subqueries.

**Please note:** The materials in this repository are primarily **PDF, Word, and PowerPoint documents**. It is a learning-resource collection—not a ready-to-run database, an application, or a repository of standalone `.sql` scripts.

## 🚀 How to Use These Materials

**1. Open the documents.** GitHub may preview some PDFs, while PowerPoint or Word documents may need to be downloaded and opened using compatible software.

**2. Select a topic.** If you're learning SQL systematically, begin with table creation and data manipulation, then move to filtering, grouping, joins, and subqueries.

**3. Practice in a database tool.** Use an SQL environment you already have access to (such as PostgreSQL, MySQL, SQL Server, or SQLite). The repo does **not** provide a preconfigured database server or a unified sample dataset.

**4. Adapt the examples.** SQL syntax differs between database systems. You may need to create sample tables and adapt vendor-specific features before running queries.

**5. Experiment.** Change predicates, JOIN conditions, and aggregation rules to understand how the results change.

## ✅ Recommended Learning Path

1. **Database basics:** Tables, columns, data types, and primary keys.
2. **Query fundamentals:** `SELECT`, `WHERE`, sorting, and filtering.
3. **Data operations:** `INSERT`, `UPDATE`, and `DELETE`.
4. **Aggregation:** `GROUP BY` and aggregate functions.
5. **Relationships:** `INNER JOIN`, `LEFT JOIN`, and multi-table queries.
6. **Advanced queries:** Subqueries, nested queries, and set operations.

This is a **suggested path through the materials**, not a formal course syllabus or a guarantee that every concept is covered in every file.
